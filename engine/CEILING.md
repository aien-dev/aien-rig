Every number has an aien-calc receipt (`aien-calc verify <id>` recomputes it; the full ids are in

Rule: a dense model reads every weight once per generated token, plus the KV cache so far. Bytes per token
divided into 672 GB/s is a hard physical limit. Real kernels reach 70 to 80 percent of nominal bandwidth
(our FP8 GEMV measured 202 to 212 GB/s of the GB10's 273, about 77 percent; see the engine README).

Budget: weights + KV cache + 512 MiB scratch must fit in 12 GiB (12,884,901,888 bytes). KV is bf16.
MXFP4 = 4-bit e2m1 weights with one 8-bit scale per 32 weights = 17/32 byte per weight.
