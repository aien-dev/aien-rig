FPS tuner

1. Scan this PC: finds settings that cost frames. 2. Find games, pick one, start it, then Measure: counts its frames for a minute and saves a receipt. 3. Apply safe changes (you see the list first). 4. Measure again to compare. Undo everything puts it all back.


  

  

    
Game mode

    
While one of the listed games runs, AIEN Rig pauses the AI engine (so the game gets all 12 GB of graphics memory) and makes sure Windows Game Mode is on. It puts both back when the game closes.
