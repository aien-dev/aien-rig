AIEN Rig for Windows (x64), built for an RTX 5070 gaming PC.

Download `aien-rig-windows-x64.zip`, extract it, open the "AIEN Rig" folder and
read README-FIRST.txt. Short version: double-click aien-rig.exe, keep the black
window open, use the page that opens in your browser.

Not tested on an RTX 5070 yet. Chat needs the WSL2 GPU path for our engine,
which is still being built (docs/WINDOWS-GPU-PATH.md in the source).

Check the download: `aien-rig-windows-x64.zip.sha256` holds its SHA-256.
